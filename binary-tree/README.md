# **Binary-tree**
Binary trees is a data structure that holds data in the form of a tree. It contains a root node which is the parent of all other nodes. The height of a tree is the number of levels it contains.

*Leaf Nodes* are nodes that have no children. 

Binary Search Trees are balanced trees where all left children are less than their parent node and their right children are greater than their parent node.
